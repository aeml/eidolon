# Wizard asset provenance

- Anatomical topology, adult proportion targets, game_engine skeleton/weights,
  and blink targets: MakeHuman Community MPFB CC0 data, local source revision
  `437dd513888a92399d1d3200d2e80859fae55abc` from
  https://github.com/makehumancommunity/mpfb2/tree/437dd513888a92399d1d3200d2e80859fae55abc/src/mpfb/data.
- Skin, fitted hair and brows: CC0 MakeHuman system assets, specifically
  `short02`, `eyebrow001`, `middleage_caucasian_male`. Source pack:
  https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip.
- Shape blending, underclothes, seams, packed material treatment, class motion,
  skinning adjustments and export preparation were authored in Blender for this
  project. Skin micro-normal detail reuses the project's Fighter material work
  on the same anatomical UVs. Iris fibers use newly authored radial textures and
  matching projected UV coordinates.
- `LICENSE-MAKEHUMAN-CC0.txt` reproduces the upstream asset license. The
  MakeHuman/MPFB application code's GPL license is separate; application code
  is not embedded in the exported character. This notice does not separately
  relicense project-specific additions.

All references above identify asset sources. No third-party viewer runtime is
included in this folder.
