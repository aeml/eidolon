# Evidence records

`releases/<version>/` contains records explicitly named for that release. A candidate, preparation, failure or rejected result retains that status; placement here does not imply acceptance.

Other dated records live under `<year>/<month>/<day>/`. `reviews/` holds retained source reviews. Original JSON receipts are retained byte for byte. Historical source paths, commands, versions and claims describe their recorded commit and time; use the current contributor map for today's layout. Markdown navigation links are rebased to retained files.

Current work belongs in [plans](../plans/), operating guidance in [operations](../operations/), and editable content inputs in [content](../content/). See the [documentation index](../README.md) for current acceptance and remaining gates.
