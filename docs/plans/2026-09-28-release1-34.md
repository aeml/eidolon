# Alpha 1.34 — safer item drops

Isolated candidate versioned 1.34.0; not pushed, deployed or accepted live.

- Dropping a stack checks that its quantity has not changed since inspection.
  If it changed during dragging or transit, inspect it and try again; no items
  are removed by the rejected request.
- The older ground-loot creation helpers now start a full pickup lifetime
  instead of expiring their loot on the first world update.
- Quest-item protections, recognizable fragment icons and existing collection
  limits remain. No rarity, Gold, experience, affix or material-rate changes.
