## Implementation

Owner approved the optional, local-only-until-shared model during preparation.

Help contains a default-off optional playtest timer. Start/Stop/Clear, explicit
activity/assistance labels, initial/latest levels and observed level30 crossing
produce only a bounded page-local aggregate. Hidden/disconnected/input-idle time
and suspended gaps are separate, not guessed active play. Eight-hour cap, clock
regression protection and late-wake handling prevent invented milestone dates.

There is no network/storage access in the timer model. The UI reads only
connection/level plus page visibility and last input time, never input contents.
Character teardown/reconstruction removes timers/listeners and local data.
An explicit stopped-summary action appends to a report draft without overwriting
existing text or submitting. Busy/oversized drafts refuse unchanged. Sharing a
report follows normal account/retention rules; clearing the timer leaves copies
already added to drafts alone. The normal report acknowledgement flow is reused.

Version/login/server/container/deploy/QA defaults and cumulative notes are
synchronized locally. The new three-viewport browser route is in mandatory
interface CI coverage. No XP/drop/reward/quest/equipment changes or campaign rerun.
