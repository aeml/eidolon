## Candidate changes

- **The right admission point.** Active Nexus and Dark King contracts point to
  Lanternhold's Dungeon Guide, not the Fourfold Portal into the shared expedition.
  From inside the Dark Realm, guidance points to the recovery camp and explains
  Recall/Return to Lanternhold. It does not invent a dungeon door in camp.
- **Prepare for all three guardians.** The existing selected-dungeon preparation
  panel explains Dissonant Herald → Null Architect → Eidolon Devourer, intervening
  chambers, MEMORY FRACTURE and leaving the marked circle. The text appears only
  for Nexus; reading it starts no action and bypasses no admission rule.
- **Claim your own Fifth Note.** A cleared Nexus directs characters with an
  accepted, unclaimed Fifth Note to Ilyra. The compact tracker names her too.
  Each character must click Complete Quest before preparing the court raid;
  boss loot alone does not unlock it. Repeat clears retain normal loot/exit
  guidance for veterans who already claimed the story quest.
- **Recovery stays familiar.** Continue uses the same run and latest cleared
  boss checkpoint. Existing encounter, checkpoint, empty-instance/logout expiry,
  eligibility, saved contracts and rewards are unchanged.
