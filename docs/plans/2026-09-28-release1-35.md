# Alpha 1.35 — safe Forge upgrades and gem crafting

Isolated candidate versioned 1.35.0; not pushed, deployed or accepted live.

- Unavailable item-level upgrades show the required character level instead
  of offering an action the server will reject.
- Level-up packets refresh the open Forge's available choices immediately.
- Near level 100, batch quotes show the actual number of levels being bought.
- Level and potency requests retain the displayed item's upgrade state. A
  repeated or stale request cannot buy another rank or upgrade replacement
  equipment; review the current preview and try again.
- Socket and gem actions also retain the displayed equipment and selected gem
  identities/quantities, protecting against changed slots and repeated removal.
- Inserting a gem consumes one gem, not its whole stack. Combining consumes
  exactly three units, including from a single stack, and requires space for
  the result before spending anything.
- Gem insertion/removal immediately refreshes authoritative combat bonuses.
- If equipment or socket contents change while removal is open, select the
  gem again; the menu no longer redirects a destructive selection silently.

No prices, material rates, potency scaling or existing gear changes. The
[Forge review](2026-09-28-1-35-forge-preflight.md) records the local checks and
passing isolated two-player/fresh-login check. Stale-preview protection applies
to updated clients sending quotes.
