# Alpha 1.39 — progression playtest context

The optional Help timer now records bounded, local summaries of class, active
time by level band, and party roster size. Active periods settle against their
previous observed context, so a level-up or party change does not relabel older
time. Hidden, disconnected, idle and suspension gaps remain separate. No player
names, member identities, inventory or coordinates are collected by the timer.
Sharing still requires appending to a draft and separately submitting a report.

The owner's campaign/pacing validation is deferred to player playtesting.
That decision and the ongoing instruction to publish the roadmap authorize
this code release while those observations stay open. This release does not
claim measured campaign balance or close A2. The target remains level30 in
2–3hours, level100 in about100hours, Dark Realm8–12hours and a suitably geared
five-player finale in5–10minutes. Forge+20 remains an endgame goal.

No fresh cohort feedback supports a numerical rebalance. Existing rewards,
rates, saves, dungeon resume and party credit rules remain. Open-alpha access
continues; closed beta requires its later near-completion gate.

Release selection is based on verified production1.38 (5a6560a7). Later local
art, audio and interface candidates are retained for their ordered releases.
Runtime, build defaults, login and cumulative notes identify1.39.0. This release
introduces no schema migration beyond inherited schema15; older schema14
writers remain fenced. CI and live verification are recorded after publication.
