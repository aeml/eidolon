## Changes

-18 keyboard actions are individually remappable or unbound: camera panning/
  lock, nearby inspection, character/bag/journal/recall/map/social/skills/
  abilities and four hotbar slots. Preferences are device-local, applied to
  existing input immediately, and do not modify saved hotbar skills or builds.
- Native selects and labeled controls expose choices, conflict feedback and
  reset. Duplicate/reserved assignments are rejected without losing focus.
  Invalid optional preferences fall back to working defaults. Blocked storage
  still applies for the session with an explicit persistence warning.
- Held camera state clears when bindings change. Key release remains safe
  after focus changes; registered preference observation is removed on dispose.
  Typing, selects, buttons and contenteditable surfaces never also cast a
  remapped ability. Browser/OS modifier shortcuts and non-repeating menu
  actions are preserved. Escape, Enter, Tab,F2 and mouse/modifier controls
  remain fixed; pointer combat is not made fully keyboard-only.
- Hotbar keys and primary Help labels reflect current bindings; nearby lore/
  portal/discovery prompts use the current inspection key, or click-only text
  if it is unbound. Detailed Help prose remains explicitly a default reference.
- Always-reduced motion is available beside the device preference. A shared
  live view suppresses foliage/courtyard/portal movement, health interpolation,
  recoil, effect movement, casino celebrations and camera punch. CSS motion is
  reduced too. OS reduction is never overridden; warning radii/timing/labels
  remain. No per-frame storage access or new observer/listener ownership.
- Removed the viewport's browser zoom prohibition. Existing camera pinch
  ownership remains on the world canvas, not native menu/account controls.
